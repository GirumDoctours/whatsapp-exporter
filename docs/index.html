Redaction

Redact PII without losing context.

Personal details become tags. The rest of each message stays exactly as written, so the redacted chats can be shared or analysed.

  • Names, numbers, emails, addresses, ages, IDs and bank details
  • ID photos replaced, text in screenshots blacked out
  • Each person keeps the same tag throughout a chat
