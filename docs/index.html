WhatsApp Exporter

Save every WhatsApp chat, photo, voice note and file into one ZIP on your Mac or Windows PC. Optionally hide names, numbers and other personal details first.

Free and open source. Unofficial: not made by or affiliated with WhatsApp or Meta.

Get it

/bin/bash -c "$(curl -fsSL https://gist.githubusercontent.com/GirumDoctours/74929d87bb6c220c23bea4d9d1b37377/raw/install.sh)"
  1. Open Terminal (⌘ Space, type Terminal, Enter), paste the line and press Enter.
  2. Pick with the arrow keys. Start with Run a quick test (10 chats, about 3 minutes).
  3. On your phone: Settings → Linked Devices → Link a Device, and scan the code.
  4. Keep WhatsApp open. The ZIP lands on your Desktop.

Needs macOS 13+ or 64-bit Windows 10/11.

Good to know

  • One folder per chat with its messages and media, plus a spreadsheet of all chats.
  • Redaction swaps details for tags, like {{PATIENT_FIRST_NAME}}. It uses Claude with your own Anthropic API key (about $1 per 10 busy chats). Check the result before sharing.
  • Everything stays on your computer, except chat text sent to Claude when you redact.
  • It links like WhatsApp Web and unlinks itself when done. Unofficial clients are against WhatsApp's terms; read-only use is low risk, but not zero.
